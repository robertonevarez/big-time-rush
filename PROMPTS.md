# Art direction & image prompts

Prompts for replacing the CSS-drawn artwork with generated images. The site's
layout, torn-paper edges, typography and motion stay as they are — the images
slot into the cover, the vinyl and the four portrait cards.

> **Current status:** `assets/cover.jpg`, `vinyl-disc.jpg`,
> `album-mockup.jpg`, `poster.jpg`, `band-group.jpg` and the four member
> portraits are already in place. The prompts below remain useful for
> regenerating or upgrading any of them; the exact filenames are listed at the
> bottom.

## Style anchor

Keep every asset in the same visual language:

- **Palette:** deep black `#0A0A0A`, bone cream `#F2E8D8`, burnt orange `#FF4A17`. Nothing else.
- **Look:** 1970s screen-printed concert poster × 1990s CD sleeve; photocopy grain, halftone dots, slightly misregistered ink, torn paper, hand-drawn stars.
- **Photography:** direct on-camera flash, hard shadows, high-contrast black-and-white with a warm orange rim light.
- **Avoid:** gradients, glossy 3D, blue/teal, neon, modern minimalism, stock-photo smiles, extra text.

## Generate in this order

1. The four portraits first (lock the grade and lighting).
2. Use those portraits as image references for the cover collage.
3. Generate the disc, then any extras.


Midjourney: append `--no extra text, watermark, logo, blue, gradient, 3D`

## Tool notes

- **Ideogram / GPT-image / ChatGPT:** best at the cover typography. Keep quoted
  text exactly as written; regenerate rather than accept a misspelling.
- **Midjourney:** generate the type-free cover (`02`) and let the site render
  the text. Add `--ar 1:1 --style raw` for covers/discs and `--ar 4:5 --style raw`
  for portraits. Use `--cref` or the Omni-Reference feature with the first
  portrait to keep the four members consistent.
- **Firefly / Photoshop:** good for cleaning up text, adding grain, and matching
  the prints.
- **Consistency:** generate all four portraits in the same session with the same
  prompt skeleton, changing only hair/beard/wardrobe. Then feed them as
  references into the cover prompt so the same four faces appear in the collage.
- **Real people:** these prompts describe fictional performers. If you want the
  actual band members' likenesses, use your own licensed photo as an image
  reference and expect limitations — most tools won't reproduce real people
  from a text description alone.
